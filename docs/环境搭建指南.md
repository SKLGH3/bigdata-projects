## 三、环境变量配置

编辑 `~/.bashrc`：

```bash
# Java
export JAVA_HOME=/opt/module/jdk1.8.0_212
export PATH=$PATH:$JAVA_HOME/bin

# Hadoop
export HADOOP_HOME=/opt/module/hadoop-3.1.3
export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin

# Hive
export HIVE_HOME=/opt/module/hive-3.1.3
export PATH=$PATH:$HIVE_HOME/bin

# Sqoop
export SQOOP_HOME=/opt/module/sqoop-1.4.7
export PATH=$PATH:$SQOOP_HOME/bin

# Flume
export FLUME_HOME=/opt/module/flume-1.9.0
export PATH=$PATH:$FLUME_HOME/bin

# HBase
export HBASE_HOME=/opt/module/hbase-2.4.11
export PATH=$PATH:$HBASE_HOME/bin

# Phoenix
export PHOENIX_HOME=/opt/module/phoenix-2.4.5
export PATH=$PATH:$PHOENIX_HOME/bin

# ZooKeeper
export ZK_HOME=/opt/module/zookeeper-3.5.7
export PATH=$PATH:$ZK_HOME/bin
```

```
source ~/.bashrc
```

## 四、服务启动命令

### 启动顺序

#### 1. 启动 ZooKeeper（所有节点）
zkServer.sh start

#### 2. 启动 HDFS
start-dfs.sh

#### 3. 启动 YARN
start-yarn.sh

#### 4. 启动 HBase
/opt/module/hbase-2.4.11/bin/start-hbase.sh

#### 5. 启动 Hive Metastore
nohup hive --service metastore > /tmp/metastore.log 2>&1 &

#### 6. 启动 HiveServer2
nohup hive --service hiveserver2 > /tmp/hiveserver2.log 2>&1 &

#### 7. 启动 MySQL
sudo systemctl start mysqld

#### 8. 启动 DataEase
/usr/local/bin/dectl start

#### 9. 启动 DolphinScheduler
cd /opt/module/dolphinscheduler-3.2.1
./bin/dolphinscheduler-daemon.sh start master-server
./bin/dolphinscheduler-daemon.sh start worker-server
./bin/dolphinscheduler-daemon.sh start api-server

### 验证服务

jps | grep -E 'NameNode|DataNode|ResourceManager|NodeManager|HMaster|HRegionServer|QuorumPeerMain'
