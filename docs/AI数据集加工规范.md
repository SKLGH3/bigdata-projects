# AI 数据集加工规范

## 数据来源

电商业务数据从 MySQL 经 Sqoop 全量或增量同步进入 Hive ODS 层，覆盖用户信息、订单、订单明细、商品资料和行为日志。ODS 保留原貌，DWD 完成清洗、去重与脱敏，DWS 按用户、商品和类目聚合，ADS 输出分析指标及 AI 可用数据集。

## 清洗规则

| 规则 | 处理方式 |
| --- | --- |
| 空值处理 | `user_id`、`order_id` 等关键字段为空时直接过滤 |
| 异常值 | 金额 ≤ 0、数量 ≤ 0、时间格式错误的订单标记为脏数据 |
| 去重 | 按 `order_id + user_id` 组合键去重，保留最新记录 |
| 脱敏 | 手机号中间 4 位替换为 `****`，地址仅保留省市 |
| 一致性 | 统一日期、金额精度和类目编码 |

## 输出标准

- 格式：Parquet + Snappy 压缩
- 质量：关键字段空值率 < 1%，主键唯一性 100%，异常记录可追溯
- 规模：模拟业务日增约 10 万条样本，记录处理前后行数及过滤原因
- 切分：训练集、验证集按用户或时间分区，避免数据泄漏

## 适用场景

数据可用于用户画像特征、推荐系统离线样本、GMV 时序预测和知识库构建。用于大模型微调时，还需转换为指令、输入、输出等标准格式。目前使用 Git 管理加工代码与元数据，正在学习 DVC，以实现数据版本可追溯、可复现和可回滚。
