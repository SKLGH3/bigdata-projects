# AI 数据集加工规范

## 数据质量

数据质量影响模型。加工时检查完整性、准确性、重复率和时效性，并为关键字段设置空值率、异常值率阈值。脏数据、错误标签和分布偏差会放大模型幻觉或预测偏差，监控应覆盖采集、清洗、产出全程。

## 样本过滤与脱敏

样本先去重、去空，过滤乱码、无意义短文本和异常值。手机号、身份证、地址采用掩码、哈希或泛化处理；训练集与验证集按用户或时间切分，避免数据泄漏，记录过滤规则与删除数量。

## 版本管理

每次产出记录数据日期、来源、Schema、脚本版本、样本量和质量指标，目录按“数据集名/版本/日期”管理。用 Git 管理代码与元数据，正在学习 DVC，计划实现大文件、流水线与实验的可追溯、可复现和可回滚。
