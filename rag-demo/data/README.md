## 加工步骤

1. 校验片名、年份和 IMDb 用户评分等核心字段。
2. 将评分、票数、预算、票房和片长统一为数值类型。
3. 按“片名 + 年份”去重，过滤 3 条核心字段缺失记录。
4. 为常见国家和电影类型增加中英双语标签。
5. 根据结构化字段生成事实摘要，供向量检索使用；未抓取或伪造剧情简介。
6. 写入获取日期、数据来源和来源 URL，保证数据可追溯。

数据仅用于学习、研究与个人作品集展示。若用于其他场景，请自行核验上游数据集及 IMDb 的使用条款。
